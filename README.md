# STRIKE ZONE · Stadium Live

선택한 1안의 1080×1920 구도를 사용하는 브라우저 데모입니다. dist/index.html을 브라우저에서 열면 실행되며, 가상 크레딧만 사용합니다. 화면 폭 540 CSS px 기준으로 디자인했으며 1080×1920 출력과 작은 모바일 화면에 비례 대응합니다.

## 동작
- 시작 크레딧 1,000 CR, 기본 베팅 100 CR, 위험 코스 3개.
- 위험 코스 1~24개. 베팅 1~1,000 CR, 최대 소수 둘째 자리.
- 25칸에 위험 코스를 균등 배치하고 라운드 동안 고정합니다.
- 클릭 시 투구 후 HIT 또는 OUT. 실패 1회로 종료합니다.
- 1회 이상 HIT 후 캐시아웃 가능. 모든 안전 칸 성공 시 자동 정산.
- 입력 잠금으로 중복 선택/정산을 방지합니다.
- 실제 돈, 계정 로그인, 입출금 기능은 없습니다. 새로고침 시 상태가 초기화됩니다.

## 수학 및 제한
P(k) = C(25-M,k)/C(25,k), 배당 X(k)=0.99/P(k) (k>=1).
배당 계산은 조합 정수와 BigInt로 수행합니다. 표시 배당은 2자리 반올림, 지급액은 내부 배당으로 계산 후 0.01 CR 미만 절사합니다. 따라서 정산 단위 적용 후 기대 반환율은 이상적인 99%에서 소폭 낮아질 수 있습니다. Stake의 지급 상한·절사·세부 운영 규칙까지 동일하게 검증한 제품은 아닙니다.

브라우저 crypto의 rejection sampling과 Fisher–Yates를 사용합니다. 클라이언트 데모이며 서버 권한 검증이나 공개 시드 기반 검증 기능은 없습니다.

## 디자인
야간 야구장, 네이비·골드, 포수 시점. 별도 생성한 배경 위에 실제 조작 가능한 HTML 보드와 정보 영역을 배치했습니다. 기존 PNG 시안 자체를 클릭 화면으로 사용하지 않습니다.

## 로컬 실행
설치 없이 dist/index.html을 열거나 Node.js로 `node server.cjs`를 실행해 안내된 주소를 엽니다.

## 2026-09-15 사용자 피드백 반영
- 1안 중계형으로 실제 플레이 가능한 데모 제작 요청.
- 배당 패널 배경 제거, 현재 배당은 투수 왼쪽·다음 성공은 오른쪽 배치.
- 배경을 위로 조정해 투수 전신을 타격존 위에 노출.
- 300개 위험 코스/성공 횟수 조합의 수학 검증 통과.
- 브라우저 HIT/OUT/상금 확정/오입력/도움말 및 4개 화면 크기 검사 통과.
- WebMCP 도구는 테스트용 레지스트리에서 호출 검증. 실제 브라우저 네이티브 WebMCP는 미지원이라 네이티브 검증은 수행하지 못함.
