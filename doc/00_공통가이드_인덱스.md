# Baseball — 개발·디자인 문서 인덱스

## 적용 우선순위

**`doc/skills`가 최우선, 디자인 MD는 그다음이다.** 두 문서가 충돌하면 스킬 규칙을 따른다. 사용자가 2026-09-16에 지정한 순서다.

1. [PixiBrown 제작 스킬](skills/SKILL.md)과 그 문서가 연결하는 세부 규칙
2. 아래 공통 디자인 가이드 `01`–`13`, 버튼 상태 가이드
3. 프로젝트의 적용 기록과 과거 작업 기록

스킬에서 정한 UI 보존 원칙에 따라 기존 POC의 조작·수치·배치·에셋을 기준으로 삼는다. 공통 가이드의 Dice/Limbo 예시, 테마, 오토·사이드 베팅을 야구 게임에 일괄 적용하지 않는다. 확률·배당·베팅 한도·서버 계약을 문서 예시 값으로 바꾸지 않는다.

## 현재 프로젝트

- **제품:** STRIKE ZONE · Stadium Live, 야구 Mines POC
- **편집 원본:** `poc/`
- **실행 산출물:** `dist/`, 시작은 `npm start`, 주소는 `http://127.0.0.1:4173/`
- **현재 구조:** [project-structure.md](project-structure.md)
- **디자인 적용·점검 결과:** [design-audit.md](design-audit.md)
- **향후 이식:** [pixibrown-migration.md](pixibrown-migration.md)

PixiBrown 템플릿 포크와 SceneMaker 프로젝트는 아직 없다. `Massive_Mines_GDD.md`, `mines-prototype.html`, `README_디자이너.md`, `디자이너_제작_가이드.md`는 이 저장소에 없으며 필수 진입 문서로 안내하지 않는다. 현재 가상 크레딧 POC와 실서버 제품 정책을 구분한다.

## 충돌할 때 적용할 규칙

| 주제 | 적용할 기준 |
|---|---|
| 없는 UI 이미지 | 임의 생성·Graphics·white_box 대체 금지. 해당 노드는 만들지 않고 필요한 파일을 기록 |
| 신규 PixiBrown UI | prefab/scene에 배치, 노드·에셋은 Serialize 연결, HTML/DOMElement 금지 |
| 기존 POC | 비교 기준을 보존. 현재 표시 값 수정은 `poc/`에서 하고 `dist`는 빌드 |
| 이미지 경로 | `raw-assets/{bundle}/images/{atlas}/file.png` |
| 사운드 경로 | `raw-assets/game/sounds/`, 신규 이름은 kebab-case |
| 반복 칸 | 아이템 prefab + 빈 Grid 호스트 + 런타임 clone |
| 요청 경로 | UI → GameMain 메서드 → Sequence.sendMessage |
| 원본 에셋 변경 후 실행 | 실제 PixiBrown 템플릿에서 build:assets:dev 먼저. 현재 POC의 npm run build와 구분 |
| 공용 팝업 | intro에 유지, game.prefab에 중복 구성하지 않음 |
