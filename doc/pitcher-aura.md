# 투수 배당 화염 오라

문서 우선순위: `doc/skills` → 디자인 MD. 현재 POC에 적용한 절차적 캔버스 FX이며, 새 이미지 에셋은 생성하지 않았다.

## 단계 기준

다음 성공 예상 배당이 아닌 **현재 획득한 실제 배당**을 기준으로 한다.

| 현재 배당 | 연출 |
|---|---|
| 2x 미만 | 오라 없음 |
| 2x 이상~4x 미만 | 낮고 은은한 주황 화염 |
| 4x 이상~8x 미만 | 더 높고 풍성한 주황 화염 |
| 8x 이상~10x 미만 | 붉은 외곽 화염과 늘어난 불티 |
| 10x 이상 | 금빛 중심, 가장 높은 화염과 많은 불티 |

- 단계 상승 시 밝기가 짧게 부드러워지며, 같은 단계에서는 애니메이션을 다시 시작하지 않는다.
- OUT·초기화·새 라운드 준비 시 즉시 꺼진다. 정산 뒤 보드 보기에서는 확정 배당의 오라를 유지한다.
- 투수 그림자와 스프라이트보다 먼저 그려지는 별도 레이어다. 공·배트·배당 UI 앞을 덮지 않는다.
- 확률·판정·배당·정산에는 영향을 주지 않는다.

## 구현과 검증

- 원본: `poc/src/game/fx/pitcher-aura.js`. 등록: `poc/build-manifest.json`.
- `game-main.js`의 화면 갱신에서 현재 라운드 상태와 배당을 전달한다.
- 기존 투수 중심에 맞춘 영역: 화면 가로 30~70%, 세로 13~30%. 반응형 크기를 관찰해 캔버스 해상도를 갱신한다.
- 불꽃의 곡선·색상 그라데이션·불티를 Canvas 2D로 그린다. 초당 최대 30회 갱신하며, 오라가 꺼졌거나 탭이 숨겨지면 반복 재생을 멈춘다.
- 동작 줄이기에서는 불티 없이 정적인 화염을 표시한다.
- 경계값 2/4/8/10x, 중복 루프 방지, 숨긴 탭·동작 줄이기·종료 정리를 자동 검사한다.
- 실제 라운드의 약 2.18x → 5.26x → 8.50x → 14.17x에서 전환을 확인했다. 320px 화면, OUT 이후 소멸, 새 라운드 초기화, 정적/동적 표시를 검증했다.

PixiBrown 이식 시 이 절차적 POC 렌더러를 그대로 복사하지 않고 `doc/skills/fx.md`의 씬·파티클 구조에 단계 기준을 옮긴다.
