## 1. 게임 규칙

alt text

### 1.1. 진행 흐름


| 단계       | 내용                                                                    |
| -------- | --------------------------------------------------------------------- |
| 게임 시작    | 난이도 & 베팅 금액 설정 → 베팅 버튼 터치 → 게임 시작 → **공개하고자 하는 셀(Cell)을 직접 터치하여 선택**  |
| 셀 공개 결과  | **성공 심볼** → 세부 타입에 따라 누적 배율 상승 → 후속 액션 선택 **실패 심볼** → 당첨금 = 0으로 게임 종료 |
| 후속 액션 선택 | 다른 셀 공개 또는 **캐시아웃** (당첨 금액 = 베팅 금액 x 누적 배율)                           |
| 게임 자동 종료 | 모든 셀이 공개되었거나 누적 배율이 10,000배를 초과했다면 자동 캐시아웃 적용                         |




### 1.2. 심볼


| 심볼      | 배율                   |
| ------- | -------------------- |
| 실패      | 기존 누적 배율에 x0 (게임 종료) |
| 성공(타입1) | 기존 누적 배율에 x1.05      |
| 성공(타입2) | 기존 누적 배율에 x1.20      |
| 성공(타입3) | 기존 누적 배율에 x1.50      |
| 성공(타입4) | 기존 누적 배율에 x5.00      |


- 게임 시작 시점의 누적 배율 = 1.00x
- 누적 배율은 곱연산으로 상승
- **최소 당첨 배율 = 1.05x**



### 1.3. 게임판

- 5 x 5 그리드 (총 25칸)
- **특정 셀 1개를 선택하여 공개하는 시점에, 확률에 따라 결과(심볼 타입) 판정**
  - **유저가 사전에 실패 심볼 갯수를 임의로 지정할 수 없으며, 총 몇 개의 실패 심볼이 묻혀있는지도 인지 불가**
    - 실패 심볼 0개인 보드판 가능
    - 실패 심볼 25개인 보드판 가능
- 게임 종료 시, 남아있는 모든 셀에 대해 확률에 따라 심볼 뽑아서 공개

## 2. 주요 인터페이스



### 2.1. 캐시아웃 버튼

alt text

- 게임이 시작되면 베팅 버튼 → 캐시아웃 버튼으로 전환
  - 첫 번째 셀 공개 전 → 비활성화
  - 성공 심볼을 찾았을 때 → 활성화
  - 실패 심볼을 찾았을 때 → 베팅 버튼
  - 새로운 셀 공개 연출 중일 때 → 비활성화
- 현재 확보한 금액을 캐시아웃 버튼 내부에 실시간으로 표시
  - 통화 기호 및 금액
  - **(베팅 금액) x (누적 배율) 값으로부터 소수점 셋째 자리 이하 값은 버림 처리**
    - **소수점 버림 처리는 누적 배율이 아닌, 최종 당첨 금액에서만 적용**
  - 예시
    - 베팅 금액 = $0.1
    - `1.05x` 3연속 당첨되었다고 가정
    - 누적 배율 = 1.05 x 1.05 x 1.05 = `1.157625x`
    - (베팅 금액) x (누적 배율) = $0.1 x 1.157625x = `$0.1157625`
      - 캐시아웃 버튼에 표시되는 금액 = $0.11
      - 캐시아웃 시 실제 획득 금액 = $0.11
      - 캐시아웃 시 결과 팝업 및 히스토리에 표시되는 배율 = 1.15x
- 캐시아웃 시 최종 획득 금액을 "WIN (통화 기호 및 금액)" 형식으로 안내
  - **다음 베팅을 실행하기 전까지는 지속 노출**



### 2.2. 결과 팝업 (일반)

alt text

- 캐시아웃(10x 미만의 당첨 배율)에 성공했을 때 등장하는 팝업
- `Win` **문구**와 함께 당첨 금액 및 배율 표시
- **금액이 리니어(선형)로 상승하는 연출 없이, 최종 결과 값이 즉시 표시됨**
- **팝업 등장 후 2초가 지나면 자동으로 닫힘**



### 2.3. 결과 팝업 (Big Win)

alt text


| 항목               | 등장 조건               |
| ---------------- | ------------------- |
| `Big Win`        | 10x ≤ 당첨 배율 < 25x   |
| `Mega Win`       | 25x ≤ 당첨 배율 < 100x  |
| `Super Mega Win` | 100x ≤ 당첨 배율 < 500x |
| `Epic Win`       | 500x ≤ 당첨 배율        |


- **모달 팝업 (닫기 위해서는 터치 필수)**
- 표시 정보
  - 팝업 문구
  - 당첨 금액
- **금액이 리니어(선형)로 상승하는 연출 없이, 최종 결과 값이 즉시 표시됨**
  - `Win → Big Win → Mega Win` **식으로 순차 상승하지 않고, 최종 당첨 배율에 해당하는 문구와 금액이 처음부터 바로 노출**
  - 터치하면 팝업 닫힘

### 3.1. 오토 베팅 경로 설정

alt text

- 오토 베팅 팝업 내에서 경로 설정 가능  
- 팝업 최초 호출 시 모든 칸 비활성화 상태
- 특정 칸 터치할 때마다 활성화 ↔ 비활성화 상태 전환
  - 모든 칸이 비활성화된 경우 오토 베팅 시작 버튼도 비활성화 (최소한 1칸은 선택 필요)  
  - 설정한 경로는 해당 세션 동안 저장 (오토 베팅 실행하지 않고 팝업 닫더라도 유지)
- 오토 베팅 실행 시 활성화 설정된 모든 칸을 **동시에** 공개하고, 실패 심볼이 하나도 없다면 캐시아웃 적용

## 5. 초기 진입 플로우 & 튜토리얼 원페이지

[프로덕트 공통 정책 (11. 초기 진입 플로우)](https://git.nwz.kr/orange/planing-hub/-/blob/master/policy/%ED%94%84%EB%A1%9C%EB%8D%95%ED%8A%B8%20%EA%B3%B5%ED%86%B5%20%EC%A0%95%EC%B1%85.md#11-%EC%B4%88%EA%B8%B0-%EC%A7%84%EC%9E%85-%ED%94%8C%EB%A1%9C%EC%9A%B0)

- 입장 절차는 공통 정책 준용 — **다운로드 → 타이틀 화면 → 튜토리얼 원페이지 팝업(1회 노출)** → 아무 곳이나 터치하면 팝업이 닫히고 베팅 가능.
- 공통 정책 11.2의 `안내 문구 1(기본 규칙)` · `안내 문구 2(보너스 규칙)`는 **아래 튜토리얼 원페이지의 상단 / 하단 문구를 가리킨다.** 원페이지에 선행하는 별도의 안내 화면은 존재하지 않는다.

| 항목           | 내용                                                                                                          |
| ------------ | ----------------------------------------------------------------------------------------------------------- |
| **최대 당첨 배율** | **해당 없음 (게임 규칙상 홍보 불가)** — 공통 정책 11.2의 `최대 당첨 배율` 항목을 사용하지 않으며, 언어키 `TUTORIAL_4`를 할당하지 않는다.                |

> **홍보 제한 준수:** 최대 당첨 배율(50,000x)은 GLI 홍보 기준을 만족하지 못하므로 튜토리얼/마케팅에서 노출하지 않는다. 아래 튜토리얼 원페이지에서도 최대 배율·기대 수익을 단정하는 표현은 사용하지 않는다.

### 5.1. 튜토리얼 원페이지

- **상단 / 하단 2개 영역**으로 구성하며, 각 영역은 **그림 + 설명 문구**로만 이루어진다. (별도 화면 레이아웃 규칙 없음)
- 상단은 **폭탄(랜덤성)**, 하단은 **심볼(배율)** 을 각각 분리하여 전달한다.
- 문구는 언어(Language) 기준 번역 노출한다. 언어키 원문 및 31개 언어 번역은 7.2. 게임 전용 다국어 팩을 따른다.

<br/>

**[ 상단 ] 폭탄 — 랜덤성 강조** (= 공통 정책 `안내 문구 1` / 기본 규칙)

| 구분 | 내용 |
| --- | --- |
| 언어키 | `TUTORIAL_1` |
| 그림 | 폭탄 개수가 **매 판 랜덤**임이 강조되는 그림 (예: 폭탄 수가 서로 다른 보드가 번갈아 바뀌는 표현) |
| 문구 (KR) | **폭탄을 피해 행운을 쟁취하세요! 매 판 폭탄의 갯수는 랜덤입니다.** |
| 문구 (EN) | **Avoid the traps and grab your fortune! The number of traps is random every round.** |

<br/>

**[ 하단 ] 심볼 — 배율 강조** (= 공통 정책 `안내 문구 2` / 보너스 규칙)

| 구분 | 내용 |
| --- | --- |
| 언어키 | `TUTORIAL_2` |
| 그림 | 서로 **다른 동물 심볼**이 **각기 다른 배율**을 가진다는 점이 강조되는 그림 (호랑이를 최고 배율로 부각) |
| 문구 (KR) | **각기 다른 동물, 각기 다른 보너스 배율! 호랑이를 찾아 빅윈 하세요!** |
| 문구 (EN) | **Different animals, different bonus multipliers! Find the Tiger for a Big Win!** |

<br/>

**[ 최하단 ] 종료 안내**

| 구분 | 내용 |

## 9. Discconect 정책

- 수동 베팅 중에 접속이 끊어진 경우
  - 현재 위치에서 캐시아웃
  - (예외1) 한 칸도 선택하지 않은 상태라면 Payout = 1배 지급하고 종료
  - (예외2) Freespin 진행 중에 한 칸도 선택하지 않은 상태라면 Payout = 0배 지급하고 종료
- 자동 베팅 중에 접속이 끊어진 경우 → 현재 라운드만 정산 처리하고 남은 자동 베팅 중단
