# POC 구조 정리 검증 기록

2026-09-15, 변경 전 POC v12.2와 구조 정리 후 실행물을 비교했다.

| 확인 | 결과 |
|---|---|
| `npm run check` | 16개 JavaScript 문법 검사 및 원본/산출물 일치 통과 |
| `npm test` | 룰·정산·전체 성공·정적 서버 테스트 4개 통과 |
| 배당 모델 | 위험 코스 1~24개, 유효 안타 수 조합 300개에서 절사 전 수학적 반환율 0.99 확인 |
| 브라우저 화면 | Chromium 540×960, 390×844에서 대기 화면 PNG가 변경 전후 바이트 단위 일치 |
| 브라우저 게임 진행 | 각 크기에서 대기/HIT/상금 확정/OUT/전체 성공 상태 5개 일치 |
| 설정과 입력 | 일반 투구, 짧게, 모션 줄이기, 소리 토글, 도움말, 다음 라운드, 초기화 실행 |
| 브라우저 오류 | 위 실행 중 JavaScript 예외 및 HTTP 400 이상 응답 없음 |
| 변경하지 않은 실행 파일 | HTML/CSS/룰 엔진/배트 렌더러/벤더/이미지 등 manifest 복사 대상 12개가 기존 파일과 바이트 단위 일치 |
| 로컬 서버 | 새 `server.cjs` 진입점 자동 빌드와 `127.0.0.1:4173` HTTP 200 확인 |

브라우저 비교에서는 테스트 세션 안에서만 난수를 고정해 같은 HIT/OUT 경로를 재현했다. 이 설정은 POC 소스나 배포 산출물에 포함하지 않았다.

로컬 비교 도구·변경 전 실행본·스크린샷은 Git 제외 폴더 `.work/`에 있다. 지속적으로 실행할 검사는 `tests/`와 `npm run check`다.

이 결과는 POC 구조 변경에 대한 검증이다. SceneMaker·PixiBrown 에셋 빌드·실서버 연동은 템플릿을 받은 뒤 별도로 검증해야 한다. 표시 배당/통화 절사에 따른 실제 반환율 검증과 이번 구조 변경 회귀 검증도 별개다.
