# 디자인 문서 적용 범위와 점검

2026-09-16. 사용자가 지정한 우선순위는 **`doc/skills` → 디자인 MD**다.

## 현재 적용 범위

현재는 HTML·JavaScript POC이며 PixiBrown 템플릿은 미제공이다. 이전에 합의한 POC 유지 범위에서 기존 UI의 표시 값과 상태만 수정한다. prefab/Serialize/에셋 빌드 조건을 충족했다고 간주하지 않는다. 새 HTML 화면, 새 아트, 새 게임 기능을 만들지 않는다.

스킬의 기존 UI 보존 규칙을 따라 야구의 골드/네이비 테마, 5×5 보드, 투수·배트, 베팅/코스 입력 형태, 라운드 규칙과 RTP 계산은 유지한다. 디자인 문서의 Deep Blue/Neon Mint 색과 Dice/Limbo/오토베팅 구성은 현재 게임에 강제 적용하지 않는다.

## 수정 전 확인한 문제

| 화면 폭(CSS px) | 헤더/잔액 영역 겹침 | 입력 패널/CTA 겹침 | 도움말 터치 폭 | 하단 문구 |
|---:|---:|---:|---:|---:|
| 320 | 9.0px | 8.3px | 25px | 8px |
| 360 | 7.9px | 4.3px | 25px | 8px |
| 390 | 7.1px | 1.4px | 25px | 8px |
| 540 | 2.9px | 겹침 없음 | 28px | 9px |

브라우저에서 실제 bounding box를 측정한 값이다. 헤더 내 줄바꿈과 폰트 행간, 고정 비율 칸보다 커진 입력 내용이 원인이었다.

| 항목 | 적용 | 근거 |

| 문서 진입점 | 없는 GDD/프로토타입 안내를 실제 POC 원본·이식 문서로 교체 | 실제 저장소 |
| 에셋 규칙 | sounds/ 경로, kebab-case, 없는 UI 이미지 대체 금지 | skills/assets.md |
| 노드·메시지 | 신규 PixiBrown 노드는 Serialize, 요청은 GameMain→Sequence | skills/client.md |
| 헤더·잔액 | 로고 줄간격·버튼 폭·잔액 행 간격 정리 | 03·05·06 |

| 베팅 입력·CTA | 입력이 자기 패널 안에 들어가도록 높이·패딩 수정 | 03·06 |

가이드의 56px는 1080 디자인 좌표이고 이번의 44px는 브라우저 CSS 좌표다. 서로 같은 단위로 취급하지 않는다. 현재 크기 변경은 기존 버튼 내부/여백의 조정이며 보드·투수·배트 좌표를 바꾸지 않는다.

UI 피드백 강도는 **2/10**, 기존 일반 투구/타격은 **4/10 유지**다. 추가 재생 시간·소리·BGM ducking 변경은 없다. 버튼 press는 모션 줄이기 설정에서 사용하지 않는다.

## 미적용 항목

- **SceneMaker/prefab/Serialize:** 템플릿 이식 후 적용. 현재 CSS 값을 prefab marker로 옮기는 일은 이식 작업이다.
- **브랜드 폰트:** 지정 폰트 파일과 확정된 야구 테마가 없어 기존 폰트를 유지한다.
- **신규 UI 이미지/사운드:** 제공·용도 확정 후 연결한다. 현재 미연결 BGM을 임의로 재생하지 않는다.
- **오토·사이드 베팅·키패드·다국어·실서버 정책:** 현재 POC에 없는 기능이며 문서 예시만으로 추가하지 않는다.
- **배트의 자연스러운 궤적:** 앞서 논의한 별도 연출 작업으로 남긴다. 이번에는 궤적/200ms 표시 구간을 변경하지 않는다.
- **Figma 일치/기기 스피커 검수:** Figma 기준과 실제 기기 비교를 수행하지 않았다.

문서의 일반 결과 연출 dim 규칙과 상호작용 모달의 배경 차단을 구분한다. 현재 결과 팝업에서는 팝업 내부 금액·버튼을 가리지 않는 기존 모달 구조를 유지한다.

## 검증

빌드·회귀 검사와 320/360/390/540 폭의 대기·HIT·결과 화면을 확인해 아래에 최종 결과를 기록한다.

### 최종 결과

- `npm run build`, `npm run check`(16개 문법 검사 및 원본/산출물 일치), `npm test`(4개) 통과.
- Chromium에서 320/360/390/540 CSS px 대기·HIT·결과 화면을 캡처했다. 320 대기, 390 대기/HIT/결과 이미지를 시각적으로 확인했다.
- 네 크기 모두 헤더/잔액, 입력/CTA, CTA/보조 문구, 보조 문구/footer 사이 겹침과 하단 잘림이 없다.
- 수정 후 헤더/잔액 최소 간격 1.59px, 입력/CTA 최소 간격 2.84px. 작은 화면에서 여유가 크지는 않지만 겹침은 해소됐다.
- 도움말/소리 버튼 영역 44×44 CSS px, 하단 문구 10~12px.
- 보드·게임 프레임·배당 영역의 위치/폭은 수정 전과 일치한다. 대기 입력과 플레이 비교 영역의 y/높이도 일치한다.
- 실제 Enter 시작, 입력 잠금, HIT→상금 확정(+12.50 CR), OUT(−100.00 CR), 모션 줄이기, 도움말·소리 토글 통과. 브라우저 예외 없음.
- 룰 엔진·배트 애니메이션·이미지 파일 변경 없음. 배트 자연스러움 개선은 별도 미완료 항목이다.
- 로컬 검증 스크립트와 캡처: `.work/design-audit.cjs`, `.work/check-design.cjs`, `.work/design-before*.png`, `.work/design-after*.png` (Git 제외).
