# CLUTCH HIT POC — 핵심 리뷰

**연속 안타에 도전하고, 멈출 시점을 선택하는 야구 테마 게임.**

[게임 실행](https://moonddu-star.github.io/baseball/) · PC / Mobile 웹 · 가상 크레딧 POC

> **현재:** 핵심 플레이와 웹·ZIP 배포 완료.
> **다음:** 처음 플레이하는 사람도 역할·실패 이유·보상 선택을 이해하는지 확인.

## 1. 무엇을 검증했나?

Tiger Mines의 선택·보상 구조를 **야구의 타격 경험**으로 바꾸는 POC임. 스윙·타구·환호를 통해 칸 선택에 타격감과 연속 성공의 보상감을 더하고자 함.

**타격존 선택 → 안타 → 보상 증가 → 계속 도전 / CASH OUT**

- **성공:** SINGLE ×1.05 / DOUBLE ×1.20 / TRIPLE ×1.50 / HOME RUN ×5.00을 누적 적용.
- **실패:** 2 STRIKES에서 시작해 한 번의 헛스윙으로 삼진·라운드 종료.
- **조작:** 타이밍을 맞추는 방식이 아닌, 5×5 타격존을 선택하는 확률형 게임.

## 2. 어디까지 구현했나?

| 핵심 요소 | 구현 결과 |
|---|---|
| 타격 경험 | 투구·스윙·타구, 결과별 타격음과 관중 환호 |
| 보상과 선택 | 연속 안타 수 강조, 배수·CASH OUT 금액 상승 연출 |
| 난이도 | EASY / MEDIUM / HARD 투수·투구폼 구분, 확률 비교 |
| 화면과 기록 | 낮·밤 경기, 모바일 UI, 최근 플레이 히트맵 |
| 공유 환경 | GitHub Pages 자동 배포 + 배포용 ZIP 생성 |

**검증:** 자동 테스트 29개 통과. 공개 웹 주소에서 시작·타격·CASH OUT 동작 확인.

## 3. 가장 중요한 피드백은?

**“야구처럼 보이지만, 내가 무엇을 하고 왜 아웃되는지 바로 이해하기 어렵다.”**

| 받은 의견 | 반영한 개선 |
|---|---|
| 내가 타자인지 투수인지 모르겠음 | YOU’RE AT BAT + 존 라이트 모션 + 목표 안내 |
| 왜 한 번 실패하면 아웃인지 모르겠음 | 2 STRIKES → 헛스윙 → 세 번째 스트라이크 → STRIKEOUT! |
| 안타가 어떤 이득인지 잘 안 보임 | 배수·금액 증가 + 첫 안타 뒤 KEEP GOING OR CASH OUT 안내 |

개선 기능은 적용했으며, **실제 이해도가 높아졌는지는 후속 리뷰에서 확인해야 함.**

## 4. 남은 과제는?

- **규칙의 기대 차이:** 실제 야구의 타이밍·주자·이닝을 기대할 수 있으나 현재는 선택·확률 게임임.
- **모바일 실기기:** 화면 잘림, 터치, 타격음은 iOS·안드로이드에서 추가 확인 필요.
- **서비스 전환:** 계정·실제 정산 서버 연동과 PixiBrown 이식은 미진행.

## 5. 다음 리뷰에서 확인할 세 가지

1. **역할:** 첫 화면만 보고 내가 타자이며 연속 안타가 목표임을 아는가?
2. **실패:** 한 번의 헛스윙이 삼진과 라운드 종료로 이어지는 이유를 이해하는가?
3. **선택:** 안타 이후 계속 도전과 CASH OUT의 차이를 아는가?

**결론: 플레이 가능한 POC는 완성됨. 다음 우선순위는 기능 추가보다 ‘처음 하는 사람도 이해하고 즐길 수 있는가’의 검증임.**
